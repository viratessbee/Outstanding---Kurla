Daily Update – Outstanding Bills

Step 1. Choose today's Excel report (the same “Customerwise Outstanding” file).
Step 2. Download the new data file.

Step 3. Upload it to GitHub:
  1. Open your GitHub repo.
  2. Add file → Upload files.
  3. Drag in data.json (it replaces the old one).
  4. Click Commit changes. In 1–2 minutes the site shows the new data.
Nothing is sent anywhere – the Excel is read inside your own browser.
